  <!-- DESCRIPCIÓN -->
  <h2>📋 Descripción</h2>
  <p>
    <strong>Odontogate</strong> es un sistema diseñado para resolver la falta de acceso a la información
    clínica por parte de los pacientes, así como facilitar la organización de consultas y procedimientos
    odontológicos. Su propósito principal es <strong>digitalizar los trámites</strong> entre pacientes y consultorios.
  </p>

  <!-- FUNCIONALIDADES -->
  <h2>✨ Funcionalidades</h2>
  <ul>
    <li>📁 Acceso digital al historial clínico del paciente</li>
    <li>📅 Gestión y agendamiento de citas odontológicas</li>
    <li>🔔 Notificaciones de recordatorio de consultas</li>
    <li>🗂️ Registro y seguimiento de procedimientos</li>
    <li>👨‍⚕️ Panel de administración para consultorios</li>
    <li>🔒 Autenticación segura de usuarios</li>
  </ul>
